# SiteCrawler

SEO-краулер для macOS 15+ на SwiftUI: обход сайта, коды ответа, SEO-теги, битые ссылки, отчёт CSV/XLSX с подсветкой.

Сборка: `./build_app.sh` → `SiteCrawler.app` (universal, подпись ad-hoc; при первом запуске: правый клик → Открыть).
Без окна: `SiteCrawler.app/Contents/MacOS/SiteCrawler --cli https://site.ru report.xlsx [--js]`
